About LightOn Karachi

LightOn Karachi is a student-friendly static website concept designed to organise general electricity information for Karachi residents.

Project goals

  • Provide a simple area-search interface.
  • Demonstrate a searchable schedule table.
  • Share general electricity safety tips.
  • Practise HTML, CSS, and JavaScript.

Current limitations

  • No backend or database.
  • No live utility data connection.
  • Forms do not send data to a server.
  • Sample area and schedule information is not official.
Before using this as a public service, add verified sources, clear update timestamps, accessibility checks, and a secure backend only if data collection is needed.
