# LightOn Karachi

A beginner-friendly, responsive static website built with HTML, CSS, and JavaScript.

## Included pages

- `index.html` — Home page
- `area-search.html` — Search sample Karachi areas
- `schedule.html` — Filterable sample schedule table
- `countdown.html` — JavaScript countdown demonstration
- `areas.html` — Sample area directory
- `area-details.html` — Reusable area detail template
- `tips.html` — General electricity safety and saving tips
- `emergency.html` — Safety information and official website link
- `faqs.html` — Frequently asked questions
- `about.html` — Project overview
- `contact.html` — Front-end contact form demo
- `feedback.html` — Front-end feedback form demo
- `disclaimer.html` — Important limitations
- `styles.css` — Shared styling
- `app.js` — Search, table filter, countdown, theme toggle, demo forms

## Run locally

1. Extract this ZIP file.
2. Open the `LightOn-Karachi` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the navigation bar to test the pages.

You can also open `index.html` directly in a browser, though a local web server is recommended.

## Important note

This is a static educational demo. It does not have a backend, database, or live connection to electricity-provider data. Area and schedule information is sample content, not official or real-time information. Contact and feedback forms do not send or save submissions.

Before publishing publicly, replace sample data with verified information, cite the source, and show the last-updated time.
## Publish with GitHub Pages

1. Create a repository on GitHub.
2. Upload the contents of this folder (not just the ZIP).
3. Open **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)` folder.
5. Save and wait for the deployment to finish.
6. Open the URL provided by GitHub Pages.

GitHub Pages hosts static sites. It does not provide a backend for these forms.
